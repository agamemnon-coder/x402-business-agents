# Partner logos: sources

Official files only, kept byte for byte as downloaded (no recolouring, cropping or stretching). Shown as one neutral
"Built with" row (`docs/assets/logos/built-with.png`, rendered by `npm run visuals` from these files, each on a white
tile with clear space around it), never inside Purser's own diagrams, and never with "certified", "endorsed",
"approved by" or "partner of". Owner's decision of 12 November: partner logos are allowed (the owner states each
partner gave permission; that permission is not itself recorded here). List of what is used: `src/visuals/logos.ts`.
