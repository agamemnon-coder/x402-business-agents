## Dry-18 (code at `3ad579a`): a miss, found and fixed

The Sourcing agent called `check_offer` and then `notify_treasury`, **without `try_purchase`**. Its run counted as
`fallback` and code did the purchase and the message as before; nothing extra was paid. Treasury (Opus) and Support
(Sonnet) decided as in dry-17. Because an agent decision did not match the evals, dry-18 does not count toward the
"three green in a row".

**Fix** (`0d0fe7a`): `notify_treasury` is refused ("not tried yet") until `try_purchase` ran; the agent then tries
and tells. Test: `test/sourcing-agent.test.ts`. Evals afterwards with real Haiku: `sourcing-cap` 5/5,
`sourcing-fits` 5/5.
