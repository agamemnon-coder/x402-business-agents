## Two bugs found and fixed during the run

1. **Relative keys folder.** The run started with `KIT11_KEYS_DIR=../x402-business-agents-keys/rehearsal-3`.
   metal-agent needs an absolute `HOME` and printed `error: …` with exit 1, which the code read as a refusal.
   So the first S2 refunds and sweep-20261029-1 were recorded as REFUSED with no reason (audit rows 132-134,
   137, 139; still visible on the dashboard). Nothing was paid twice: the resumed run paid the refunds once
   (rows 144-146) and found refund-7 already paid on the second pass (row 148). Fixed: `keysDir` is made
   absolute, and an `error:` line from the CLI now throws instead of counting as a refusal (test in
   `test/agent-cli.test.ts`).
2. **Comma decimals on the phone.** The iPhone's decimal keypad has only a comma. Max's first policy change
   ("0,03") was signed, then refused by the runner as a bad format, so nothing changed. Fixed: the page reads
   `0,03` as `0.03` and checks the amount before Face ID is asked for (`normalizeAmount`, `amountProblem` in
   `src/approve/client.ts`; the browser check types `0,03`).
