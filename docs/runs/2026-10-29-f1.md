## Found on the way

A first attempt in the dev world went differently, and it found a bug:

- Max's "yes" came in 14 s **before** the expiry, so the approval was valid. The executor then refused before
  calling Airwallex: EUR would end below its floor plus commitments. Nothing moved; P-0005 there stays
  unexecuted and expires.
- Cause: the rehearsals paid from the same sandbox, so the dev world's committed EUR was 2,987.56 short, and
  `planInvoice` treated a negative free balance as zero. Fixed in `58301ce`: no plan is made when the reserve is
  already short; the agent escalates with the size of the gap and quotes nothing.
- For the next F1 attempt Claude waited until the proposal had expired before asking.
