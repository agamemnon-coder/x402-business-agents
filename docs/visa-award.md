# Visa Award

Moved from the [README](../README.md) on 15 November, to keep it short.

Visa Intelligent Commerce through Airwallex's Airi: an agent pays with a Visa credential Purser binds to one purchase; in the sandbox Airi/Airwallex did not refuse a reuse or a higher amount ([vic-3](runs/2026-11-12-vic-3.md)), Purser did ([vic-4](runs/2026-11-13-vic-4.md)); within the CFO's limit on its own and above it only after the CFO's passkey. Live in the Airwallex sandbox with a test card on 7 November (a scripted run, no Claude call; [first run](runs/2026-11-07-vic-1.md)), 12, 13 and 14 November: 1 paid in the 14 Nov run (6 paid across 4 Visa runs). The 14 Nov run is the whole story in one record: the agent asks, Purser waits for the CFO's Face ID on the exact terms, Airi's mandate carries that hash, one tap in Airi, paid; then the same credential, for another amount and a second time, refused by Purser before any Airwallex call ([latest run](runs/2026-11-14-vic-5.md); [13 Nov](runs/2026-11-13-vic-4.md)). Test money only.

What Visa Intelligent Commerce asks for, in Visa's developer docs (read 14 November; [sources](plans/visa-1114.md)), and how Purser meets it in these runs. **Payment credential:** Purser binds Airi's credential to one purchase (another amount: `PURSER_CREDENTIAL_AMOUNT_MISMATCH`; a second use: `PURSER_CREDENTIAL_ALREADY_USED`; before any Airwallex call); Airi's credential, not a Visa agentic token. **Consumer authentication:** above the CFO's limit, the CFO's passkey (Face ID) signs the SHA-256 of the exact terms, read back from Airi's mandate and Airwallex's PaymentIntent; Purser's passkey, not a Visa Payment Passkey. **Intent, consent and limits:** the CFO's limits in Purser's code (the agent alone up to EUR 20.00, 3 a day; a hard cap; an allowlist of merchants), each step in Purser's hash-chained audit log. **Agent identity:** not done in the Airi runs. Visa TAP is an extra, not part of the entry. A separate run on 2 November signed the agent's checkout and Visa's reference verifier accepted it, against a self-hosted reference registry with a test key ([record](runs/visa-tap-live-2026-11-02.json)).

Not proven yet: a Visa-provisioned agentic token, a real card or real money, registration with Visa as an agent, Signals to Visa. [/visa](https://kit11.max-31b.workers.dev/visa)
