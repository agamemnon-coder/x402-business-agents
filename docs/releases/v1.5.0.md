## New in v1.5.0: the governance round (21 to 26 November)

Read against Airwallex's "Agentic banking starts with governance": [docs/governance.md](https://github.com/agamemnon-coder/x402-business-agents/blob/main/docs/governance.md) maps each principle to the code that holds it, the test that proves it and the live record, and says plainly what is not done.

### Governance
- **The CFO's emergency stop in Purser Cloud.** `POST /v1/engine/emergency-stop` files the stop as a policy change; it takes effect only when the CFO approves it with the passkey, and lifting it is signed the same way. While on: nothing is planned, no agent pays alone, an approval pays nothing, the routed rail asks once more right before every create at either bank, and no agent card is issued, unfrozen or raised. API only for now; a console button follows.
- **Several legal entities, each paying only from its own account.** The terms the CFO signs carry the paying entity and its funding account, so changing either breaks the signature like one changed cent. An agent pays from an entity only where the CFO signed `pay_from.<entity>.<agent>` allowed. Built and tested; no recorded sandbox run with two entities yet.
- **Segregation of duties for policy changes.** Above `approval.policy_sod_eur` (off until set), loosening the CFO policy needs the passkeys of two different people; whoever proposed a change never approves it. Tightening stays one person.
- **A signed audit pack per period.** `npm run audit-pack -- --from … --to …` writes one bundle: the period's audit rows with their hash chain back to genesis, sorted into decisions, approvals, policy changes, refusals and holds, and reconciliation, with an Ed25519-signed manifest. `npm run verify-audit-pack` checks it offline and names the section and row that fail.
- **Airwallex AgentOS alongside Purser.** AgentOS reads and prepares but does not initiate transfers, payouts or FX. Purser's MCP server gains `route_money_out`, a read-only tool that finds the checked invoice a transfer would pay and the next step; a guessed money tool name is refused and pointed at it. [docs/agentos.md](https://github.com/agamemnon-coder/x402-business-agents/blob/main/docs/agentos.md). Not an official integration.

## Upgrade and security notes
- **No database migration.** Companies without entities hash and behave exactly as before; segregation of duties is off until the CFO sets its threshold.
- **New:** the Cloud route `POST /v1/engine/emergency-stop` (OpenAPI updated), the MCP tool `route_money_out`, and the CLIs `audit-pack` and `verify-audit-pack`.
- **Fuzzing**: the nightly proof-bundle suite was rerun on three seeds; all 17 properties held.
- **Vulnerabilities fixed**: the three CodeQL findings and the `wcmatch` advisory above.
