**AI agents pay supplier invoices within the limits you set. Above a limit, the CFO signs the exact terms with a passkey (Face ID), and one changed cent breaks the signature.**

Test money only: the Airwallex sandbox and the Alta (formerly Metal) testnet. No real money moves; what is simulated is labelled in each record.

## New in v1.3.2: the outside audit round (20 November)

An outside weak-points audit of 20 November listed what Purser still lacked. This release closes what code can close, with live sandbox evidence where possible.

### Safer approvals
- **An approved payment that cannot run no longer stalls in silence.** It is marked "blocked, needs review", raises a `/health` alarm and is not retried; a person sends it back for a new approval.
- **A passkey written straight into the runner's database approves nothing.** Each passkey is sealed at enrolment with a key outside the database.
- **Signed audit checkpoints.** With a checkpoint key set, a cut, rewritten or forged audit log is found before the next payment, loosening policy change or key enrolment. Built and tested locally, not yet deployed.
- **The approval pages allow only their own recorded script.** Each page's content security policy lists the exact SHA-256 of its script and style, and `npm run verify-approval-page` checks a live page against the record.
- **Every company owner is told** when a key is added, replaced or removed, and at each recovery step.

### Proven live (sandbox and testnet, 20 November)
- **Emergency stop drill:** every agent payment was refused in about 0.1 s and every agent card read INACTIVE at Airwallex in about 3.4 s. [Record](https://github.com/agamemnon-coder/x402-business-agents/blob/main/docs/runs/2026-11-20-stop-drill.md)
- **Card drill:** freeze, thaw and refreeze measured at 0.6 to 0.9 s a step; four bugs found and fixed. [Record](https://github.com/agamemnon-coder/x402-business-agents/blob/main/docs/runs/2026-11-20-card-drill.md)
- **Airwallex replay check:** 9 of 9 repeated creates refused, one object per request id. [Record](https://github.com/agamemnon-coder/x402-business-agents/blob/main/docs/runs/2026-11-20-airwallex-replay.md)
- **Alta refusals:** 4 of 4 refused on chain with the expected reason, 0.00 moved. [Record](https://github.com/agamemnon-coder/x402-business-agents/blob/main/docs/runs/2026-11-20-alta-refusals.md)

### Bugs fixed
- A re-run after a lost Airwallex payout resent it without checking the EUR reserve floor.
- Two of Airwallex's answers to a repeated request were read as "nothing moved".
- A malformed amount gave the wrong refusal reason (nothing was paid either way).

### Privacy, site and quality
- A data inventory, a retention policy, a `/privacy` page and company offboarding through the API.
- The Airwallex API version is pinned (2025-11-11) on every call except FX, as the kit asks; tested offline.
- Site: accessibility and contrast fixes, a pilot and partnership contact in the footer, and pages search engines can index.
- `llms.txt` rewritten: what is live, what is simulated, how to check it.
- 21 new coverage test files and 18 floor tests; the coverage floor is now 91% statements, 80% branches.

## Upgrade and security notes
- **No database migration** in this release.
- **A runner with an enrolment seal key** (`PURSER_ENROLMENT_SEAL_KEY`): seal each passkey enrolled before this release once, with `npm run passkey -- seal <fingerprint>`, after comparing the fingerprint with the phone. Without a seal key nothing changes.
- The version is 1.3.2 in `package.json`, `server.json` and the MCP server.
- No externally reported vulnerabilities were fixed in this release ([SECURITY.md](https://github.com/agamemnon-coder/x402-business-agents/blob/main/SECURITY.md)).
