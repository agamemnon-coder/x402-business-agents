How Purser uses Metal

On Metal, Northwind's agents pay on chain, in cents, under mandates bound on chain, which Metal enforces. Purser is the CFO's control layer on top: it sets the mandates, asks for Face ID before any limit goes up, and checks every payment afterwards. Everything below ran on Metal testnet with test money, in the recorded run or in the separate run each card names; each card links to its proof and to Metal's docs.
